Claude Code Setup — Windows & VS Code

Connect VS Code to the shared AI proxy. Estimated setup time: 5 minutes.
1

Prerequisites

Make sure these are already installed before continuing.

  • VS Code — code.visualstudio.com
  • Claude Code extension — search "Claude Code" in the VS Code Extensions panel (Ctrl+Shift+X) and install the one by Anthropic
ℹ️
You do not need an Anthropic account or a personal API key. Your access key will be provided by the admin.
2

Get your Access Key

You will receive a personal access key from the admin that looks like this:

sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Each key has a monthly spending limit. When the limit is reached, the key stops working until the next billing cycle — you won't be charged anything personally.

⚠️
Keep your key private. Do not share it or commit it to any repository. If you think your key has been exposed, contact the admin immediately for a replacement.
3

Set Environment Variables

Claude Code reads two environment variables to know where to send requests. Set them at the Windows user level so all applications pick them up automatically.

Open Environment Variables:

Win + R
→
sysdm.cpl
→
Advanced
→
Environment Variables

Under User variables, click New and add these two entries:

Variable NameValue
ANTHROPIC_API_KEY sk-your-key-provided-by-admin
ANTHROPIC_BASE_URL http://20.196.220.238:4000
ℹ️
ANTHROPIC_BASE_URL tells Claude Code to route requests through the shared proxy instead of directly to Anthropic. This is what enables usage tracking and budget limits.
4

Restart VS Code

Environment variables are read when an application launches. You must fully close and reopen VS Code for the changes to take effect.

  1. Close all VS Code windows
  2. Wait a moment for the process to exit completely
  3. Reopen VS Code
5

Verify the Setup

Open the VS Code integrated terminal (Ctrl + `) and run:

echo $env:ANTHROPIC_BASE_URL echo $env:ANTHROPIC_API_KEY

Expected output:

http://20.196.220.238:4000 sk-your-key-here
⚠️
If either line is blank, the environment variable was not saved correctly. Close VS Code, re-check Step 3, and reopen.
6

Test Claude Code

Open the Claude Code panel in VS Code and send a message. If you see a response, setup is complete.

✅
You're all set. Your usage is being tracked and will stay within your assigned budget automatically.

Quick checklist:

  • Claude Code extension installed
  • ANTHROPIC_API_KEY set to provided key
  • ANTHROPIC_BASE_URL set to proxy address
  • VS Code restarted after setting variables
  • Environment variables visible in terminal
  • Claude Code responds to a test message
Need help? If you encounter any issues or your key stops working, contact the admin. Do not attempt to create a new Anthropic account or API key — all access is managed through the shared proxy.

Claude Code Setup — Windows & VS Code

Connect VS Code to the shared AI proxy. Estimated setup time: 5 minutes.
1

Prerequisites

Make sure these are already installed before continuing.

  • VS Code — code.visualstudio.com
  • Claude Code extension — search "Claude Code" in the VS Code Extensions panel (Ctrl+Shift+X) and install the one by Anthropic
ℹ️
You do not need an Anthropic account or a personal API key. Your access key will be provided by the admin.
2

Get your Access Key

You will receive a personal access key from the admin that looks like this:

sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Each key has a monthly spending limit. When the limit is reached, the key stops working until the next billing cycle — you won't be charged anything personally.

⚠️
Keep your key private. Do not share it or commit it to any repository. If you think your key has been exposed, contact the admin immediately for a replacement.
3

Configure Claude Code

Open the VS Code integrated terminal (Ctrl + `) and run these two commands. Replace the placeholder with your actual key from Step 2.

claude config set -g apiKey "sk-your-key-from-admin" claude config set -g apiBaseUrl "http://20.196.220.238:4000"
ℹ️
Why this method? claude config set stores your key in a secure settings file — safer than plaintext system variables, and only accessible to Claude Code.
⚠️
Run these commands in the VS Code terminal, not PowerShell or Command Prompt opened separately.
4

Verify the Configuration

In the same terminal, confirm both settings were saved:

claude config list

You should see output that includes:

apiKey: sk-your-key-here apiBaseUrl: http://20.196.220.238:4000
⚠️
If apiBaseUrl is missing or blank, re-run the second command from Step 3 and check for typos.
5

Test Claude Code

Open the Claude Code panel in VS Code and send a message. If you see a response, setup is complete. No restart is required.

✅
You're all set. Your usage is being tracked and will stay within your assigned budget automatically.

Quick checklist:

  • Claude Code extension installed
  • Access key received from admin
  • claude config set -g apiKey completed
  • claude config set -g apiBaseUrl completed
  • claude config list shows both values
  • Claude Code responds to a test message
Optional

Switching Between the Proxy and Your Personal Claude Account

If you also have your own Anthropic API key or a claude.ai subscription, you can set up use-proxy / use-direct commands to switch between the two instantly from any terminal.

Option A — You have your own Anthropic API key

One-time setup. After this you can type use-proxy or use-direct in any terminal to switch instantly.

Step 1 — Copy the script below into Notepad (or any text editor). Replace the two placeholder keys with your actual keys, then copy the whole edited block.

$prof = "$env:USERPROFILE\Documents\PowerShell\Microsoft.PowerShell_profile.ps1" md "$env:USERPROFILE\Documents\PowerShell" -Force | Out-Null Add-Content $prof 'function use-proxy { claude config set -g apiKey "sk-your-virtual-key"; claude config set -g apiBaseUrl "http://20.196.220.238:4000"; Write-Host "Switched to: Proxy Mode" }' Add-Content $prof 'function use-direct { claude config set -g apiKey "sk-ant-your-personal-key"; claude config set -g apiBaseUrl ""; Write-Host "Switched to: Direct Mode" }' Write-Host "Done. Close this window and open a new terminal to use use-proxy / use-direct."
ℹ️
Edit the two keys in Notepad before copying — do not run the script with the placeholder text still in it.

Step 2 — Open Windows PowerShell from the Start menu (search "powershell"). Paste the edited script and press Enter.

You should see "Done. Close this window…" — that means it worked.

Step 3 — Close PowerShell and open a new terminal. Type:

use-proxy

You should see "Switched to: Proxy Mode". The commands work in any new terminal from now on — PowerShell, VS Code terminal, or Windows Terminal.

Option B — You use a claude.ai subscription (OAuth login)

Claude Code can only use one auth method at a time. Use the commands below — no manual login/logout required in most cases.

DirectionCommand to run in terminal
Personal → Proxy use-proxy (set up in Option A above)
Proxy → Personal use-direct — clears the proxy key and URL; Claude Code automatically falls back to your existing claude.ai session
⚠️
If you see "Auth conflict: both a token and an API key are set" after switching, run /logout inside Claude Code once to clear it, then run use-proxy or use-direct again.
Need help? If you encounter any issues or your key stops working, contact the admin. Do not attempt to create a new Anthropic account or API key — all access is managed through the shared proxy.
